# Bouri Events Monorepo

Structure actuelle :

- `backend/` : futur backend **Spring Boot** (a implementer).
- `frontend/` : application **React + Vite + TypeScript**.

## Lancer le frontend (MVP actuel)

```bash
cd frontend
npm install
npm run dev
```

## Build production frontend

```bash
cd frontend
npm run build
```

Le backend n'est pas encore code dans cette etape.
